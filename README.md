# 사장님도 퇴근합니다

자영업 사장님들이 가게 운영 경험과 고민을 나누는 커뮤니티 프로젝트입니다.

## 프로젝트 진행 현황

- **완료:** 1~11단계
- **현재 보완 완료:** 게시글 상세 본인 수정 버튼, 마이페이지 5개 페이지네이션, 회원 상세 최근 활동 5개, 관리자 목록 20개 페이지네이션
- **작업 원칙:** 실제 코드와 Supabase 동작을 확인한 뒤 한 단계씩 진행합니다. 기존 기능과 디자인을 불필요하게 깨뜨리지 않고, 구현 후 실제 사용자 테스트를 거쳐 완료 처리합니다.

## 실행

```bat
cd D:\sajangnim-community
git pull origin main
py -m http.server 3000
```

브라우저: **http://localhost:3000**

수정 후에는 `git pull origin main` 후 브라우저에서 `Ctrl + F5`로 강력 새로고침합니다.

> Git 충돌이 발생하면 임의로 `git reset --hard`를 실행하지 말고 `git status`와 오류 메시지를 먼저 확인합니다.

## 현재 주요 기능

### 회원/마이페이지
- 이메일, Google, Kakao 로그인
- 프로필 닉네임·업종·소개 수정
- 내가 작성한 게시글: **페이지당 5개**
- 내가 작성한 댓글: **페이지당 5개**
- 각 목록에 이전/다음 페이지 이동 및 전체 개수 표시

### 게시글
- 작성·목록·상세·검색
- 카테고리·업종·익명 작성
- 조회수
- 본인 게시글 상세에서 **✏️ 수정 버튼 표시**
- 마이페이지에서도 본인 게시글 수정 가능
- 수정 후 상세 화면의 제목/본문만 갱신하여 조회수가 중복 증가하지 않도록 처리
- 상태: `ACTIVE / HIDDEN / DELETED`

### 댓글/공감/신고
- 댓글 작성·수정·삭제·신고
- 공감 5종 등록/취소
- 게시글/댓글 신고 및 중복 신고 방지
- 신고 상태: `PENDING / REJECTED / RESOLVED`

## 관리자 시스템

- 관리자 대시보드
- 신고/게시글/댓글/회원 관리
- 관리자 통합검색
- 상태 한글화 및 색상 배지
- 게시글/댓글 상세 즉시 숨김·삭제·복구
- 회원 활동 상세
- 신고/게시글/댓글 목록: **페이지당 20건**
- 회원 목록: **페이지당 20명**
- 역할/상태/업종 필터 및 회원 검색
- 회원 선택 → 회원정보에서 **최근 게시글 5개 / 최근 댓글 5개** 표시
- 서버 전체 통합검색은 분류별 최대 100건 검색 유지

## 관리자 전용 Supabase RPC

- `admin_get_report_target`
- `admin_set_report_target_status`
- `admin_list_comments`
- `admin_list_post_comments`
- `admin_page_reports`
- `admin_page_posts`
- `admin_page_comments`
- `admin_unified_search`
- `admin_page_members`

관리자용 RPC는 `SECURITY DEFINER`를 사용하고 함수 내부에서 `auth.uid()`, 관리자/운영자 역할, ACTIVE 상태를 검사합니다. 관리자 RPC의 `anon` 실행권한은 회수했고 일반회원이 직접 호출하면 차단됩니다.

## 11단계 관리자 보안 — 완료

- `profiles/posts/comments/reports/reactions` 핵심 5개 테이블 RLS 활성 확인
- `posts/profiles/reactions` 최소 권한 적용
- 일반회원 게시글 작성/본인 수정/본인 삭제만 허용
- 프로필은 본인 닉네임·업종·소개 수정만 허용
- 브라우저에서 `profiles.role/status` 직접 변경 차단
- 공감 등록/취소는 로그인 회원 본인만 허용
- 신고 INSERT는 본인 `reporter_id + PENDING`으로 제한
- 관리자 함수 `SECURITY DEFINER + search_path=""` 확인
- 일반회원 `role=ADMIN` 직접 변경 시도 → HTTP 403 확인
- 일반회원 `admin_page_members` 직접 호출 시도 → HTTP 403 확인
- `config.js`에는 브라우저용 publishable 키만 사용하고 `service_role` 키는 두지 않음

## 주요 파일

- `index.html` — 페이지 구조
- `style.css` — 전체 UI 스타일
- `app.js` — 회원·게시글·댓글·공감·신고·관리자 기본 기능
- `config.js` — Supabase 설정 및 보완 스크립트 로드
- `post-mypage-pagination.js` — **게시글 상세 본인 수정 버튼 + 마이페이지 게시글/댓글 5개 페이지네이션**
- `post-edit-refresh-fix.js` — **게시글 수정 후 상세 화면 갱신 및 조회수 중복 증가 방지**
- `admin-comment-fix.js` — 관리자 신고/댓글 조회 및 통합검색 보완
- `admin-ui-actions.js` — 관리자 상태 한글화·색상 및 상세 즉시 조치 UI
- `admin-member-detail-fix.js` — **회원 상세 역할/상태 한글화 + 최근 게시글/댓글 5개 표시**
- `admin-pagination-search.js` — **신고/게시글/댓글 20건 페이지네이션 + 서버 전체검색**
- `admin-members-pagination.js` — **회원 20명 페이지네이션 및 필터/검색**
- `supabase-admin-pagination-search.sql` — 신고/게시글/댓글/전체검색 관리자 RPC
- `supabase-admin-members-pagination.sql` — 회원목록 관리자 RPC
- `supabase-step11-security-hardening.sql` — 11단계 관리자 함수/프로필 보안
- `supabase-step11-rls-audit.sql` — RLS/GRANT/정책 감사
- `supabase-step11-rls-hardening.sql` — 주요 테이블 RLS/최소권한 하드닝
